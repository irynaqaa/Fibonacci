Input Data Format Specifications
====================================

The input data format specifications are as follows:

* The input data should be a dictionary with the following keys: 'id', 'name', 'age', 'email'.
* The 'id' key should contain a unique integer value.
* The 'name' key should contain a string value.
* The 'age' key should contain an integer value between 18 and 100.
* The 'email' key should contain a string value in the format of a valid email address.
