# Data Processing Application

## Overview
This application processes input data files and generates reports.

## Installation
1. Clone the repository.
2. Install dependencies.

## Usage
Run the application using the command line:
```
python cli.py process --file <input_file>
python cli.py report --file <input_file> --format <csv|json>
```

## Configuration
Configuration settings can be managed via `config.json` file.

## Testing
Run tests using pytest:
```
pytest tests/
```
