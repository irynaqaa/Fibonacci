# React Application
This is a React application created using create-react-app.
## Expense Tracker
A simple expense tracking application built with React and React Native SQLite Storage.
## Features
* Add transactions
* View transactions
* Edit transactions
* Delete transactions
* Add categories
* View categories
* Edit categories
* Delete categories
* Add users
* View users
* Edit users
* Delete users
## Installation
1. Clone the repository
2. Run `npm install` to install dependencies
3. Run `npm start` to start the application
## Usage
1. Open the application in your web browser
2. Click on the "Add Transaction" button to add a new transaction
3. Click on the "View Transactions" button to view all transactions
4. Click on the "Edit Transaction" button to edit a transaction
5. Click on the "Delete Transaction" button to delete a transaction
6. Click on the "Add Category" button to add a new category
7. Click on the "View Categories" button to view all categories
8. Click on the "Edit Category" button to edit a category
9. Click on the "Delete Category" button to delete a category
10. Click on the "Add User" button to add a new user
11. Click on the "View Users" button to view all users
12. Click on the "Edit User" button to edit a user
13. Click on the "Delete User" button to delete a user
